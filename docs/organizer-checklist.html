T-60

  • Admin logged in, charger in. Dashboard: phase Waiting, no warnings, 4 cases, no CASE-SAMPLE.
  • Projector on /screen, full screen, shows "Waiting".
  • Check-in desk: Teams page open, slips sorted by code; blank slips for walk-ins.
  • Walk-in: Teams → Add one team → write down code + PIN.
  • Judges have their logins and a printed SOLUTIONS copy each.

T-30

  • Teams log in (staggered as they check in). Control room: teams shown red = no login / no case.
  • Brief: one person edits the timeline, one the report; show "What do these mean?" tag rules.
  • Tell teams: do NOT press Log out (it logs out all their devices).
  • Tell teams: saving is automatic; "No connection" = keep the tab open.

T-10

  • Control room step 1 timer set to min.
  • Everyone who will click something knows: only the Driver clicks phase buttons.

INVESTIGATION

  • Lost time for one team → +5 on its row (note: also applies to later phases).
  • Everyone short of time → Extend deadline.

LOCK

TWIST

IF SOMETHING GOES WRONG

Login fails"Wrong code or PIN" → check the slip (AIF-0XX, 6 digits). "Too many attempts" → Teams → More → Reset PIN. "Login server is busy" → wait 30 s; stagger logins; owner raises the Supabase rate limit.
Team's data isn't savingLook at their save indicator. "No connection" → Wi-Fi, keep the tab open. "Teammate changed this" → copy text, click load the latest version, one editor only. "Time up / closed" → deadline passed or already submitted → +5 or unlock if fair. Control room shows their Last activity.
Wi-Fi drops (room)Pause the clock: Extend deadline by the outage. Edits are kept in open tabs and save on reconnect. Long outage → paper forms + printed case copies.
Submission fails"Couldn't confirm" → press Submit again (safe, never duplicates). Check the Report page for green "Submitted at", or the Control room status. Unsubmitted work is auto-locked and still scored.
Admin clicked something by mistakeSTOP, don't click more. Wrong timer → Change timer. Submitted by mistake → unlock (only while that phase runs). Wrong phase → going back needs BACK and does not unlock reports; usually better to continue. Never press Reset during the event.
Judge can't access a team"View only / not assigned" → Results → Assign judges again (scores are kept) or check the judge is in the top-N list. Presentation box missing → the team isn't shortlisted. Judge can't log in → check email/password (admin can reset it in Supabase); meanwhile note scores on paper.
